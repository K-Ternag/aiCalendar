데이터 처리 안내

내 일정은,
내 손 안에.

선택한 학교 안내와 메시지, 개인·공유 캘린더, 구글 일정 가져오기와 서비스 AI의 데이터 처리 흐름을 현재 앱 구현과 화면 기준으로 설명합니다.

01 · 일정과 체크리스트

사용자가 내용을 확인하고 직접 저장해야 일정으로 등록됩니다. 개인·공유 캘린더를 선택하고 공유 멤버의 편집·읽기 권한을 관리하는 화면을 제공합니다. 공유 상태는 설명용 예시이며 실제 초대 발송과 실기기 동작은 미검증입니다.

02 · 선택적 서비스 AI 분석

AI 분석을 시작하면 선택한 문자·사진이 서비스 서버를 거쳐 OpenAI로 전달됩니다. 문자·사진에 포함된 이름·연락처 등 개인정보도 전송될 수 있으므로 불필요한 정보는 지우거나 가려 주세요. 개인정보 수집·이용과 국외 이전 동의가 모두 필요합니다.

동의 화면은 서비스 서버가 입력 원문·사진을 보관하지 않으며 분석 결과는 24시간 동안 조회할 수 있다고 안내합니다. 추가 준비물 추천에는 선택한 일정 정보도 전달됩니다. 이 안내는 현재 앱 화면에 표시된 내용이며 실제 AI 호출은 미검증입니다.

03 · 회원·구독과 이용권

앱 이용 전 카카오 가입·로그인, 별명 설정과 AI 사용 선택을 완료해야 합니다. AI 없이 시작하기도 선택할 수 있습니다. 회원 화면에서 체험·구독 이용권, 남은 AI 횟수, 문의용 회원 ID와 복사, 구독 상품 확인·복원, 로그아웃·회원 탈퇴를 제공합니다. 화면의 회원·이용권 상태는 예시이며 실제 카카오 로그인·Google Play 결제의 전체 흐름은 별도 확인 대상입니다.

04 · 카카오톡 알림 원문

사용자가 Android 알림 접근 권한을 허용하고 채팅방 또는 발신자 이름 조건을 설정할 수 있습니다. 조건에 맞는 알림 원문을 앱에서 보관합니다. 수집·필터 단계에서 AI를 실행하거나 OpenAI에 원문을 전달하지 않습니다. 사용자가 원문을 선택해 일정 확인을 열었을 때 분석하며 전체 대화 기록을 읽는 기능은 아닙니다.

05 · 공유·붙여넣기와 기본 텍스트 분석

AI 없이 시작하기를 선택하거나 AI 사용을 끈 경우, 공유·붙여넣은 텍스트는 기기 안의 규칙 기반 분석으로 일정 항목을 채웁니다. AI 연결이나 모델 다운로드가 필요 없으며, 이 분석은 원문을 OpenAI로 보내지 않습니다. 클립보드는 붙여넣기 동작을 할 때만 읽고 백그라운드에서 감시하지 않습니다. 문자 알림을 자동 수집하지 않으며 사용자가 확인 후 저장해야 일정으로 등록됩니다. 사진 분석에는 회원·동의·유효한 AI 이용권이 필요합니다.

06 · 구글 일정 가져오기

Android 캘린더 읽기 권한으로 이 기기에 동기화된 구글 캘린더만 조회합니다. 별도의 구글 로그인이나 쓰기 권한은 요청하지 않으며 구글 원본을 수정하지 않습니다. 사용자가 선택하고 저장을 확인한 일정의 제목·기간·시간대·종일 여부·장소·메모를 회원의 개인·공유 캘린더로 복사합니다. 공유 대상의 멤버는 가져온 일정을 볼 수 있습니다.

선택하지 않은 일정 내용과 구글 계정 주소는 서버로 보내지 않습니다. 미리보기의 중복 확인에는 익명화한 출처 키를 사용합니다. 원래 알림·참석자·첨부파일·회의 응답·색은 복사하지 않고 알림은 없음으로 저장됩니다. 반복은 선택 기간의 개별 회차로 저장하며 이후 구글 변경은 자동 반영하지 않습니다. 같은 설치에서 원본 식별자가 유지되는 범위의 중복을 구분하며 재설치나 다른 기기에서는 중복 판별을 보장하지 않습니다.

화면은 합성 일정 예시입니다. 앱 문서에는 합성 데이터를 이용한 기기 캘린더·화면·저장 검증이 기록되어 있으며, 실제 구글 계정과 실기기의 전체 가져오기 흐름은 별도 확인 대상입니다.

07 · 이 소개 웹사이트

정적 제품 소개 사이트로 로그인, AI 분석, 문의 양식이나 일정 데이터베이스가 없습니다. 분석 추적 스크립트와 외부 삽입 콘텐츠를 사용하지 않습니다. 언어 선택은 현재 브라우저의 로컬 저장소에만 저장하며 앱 개발자에게 전송하지 않습니다. GitHub Pages에 호스팅하는 경우 호스팅 요청은 GitHub의 정책에 따라 처리됩니다.

08 · 서비스 상태

앱은 개발 중입니다. AI 결과와 회원·공유 캘린더 상태는 설명용 예시이며 실제 AI 호출, Google Play 결제, 초대 발송과 실기기 동작은 미검증입니다. 사진 분석 전 회원·동의·유효한 이용권과 분석 준비 상태·남은 횟수를 확인해야 합니다.

이 페이지는 기능별 데이터 처리 안내입니다. 전체 개인정보처리방침과 삭제 요청 방법은 별도 페이지에서 확인하세요. 개인정보처리방침은 2026년 10월 23일부터 시행합니다.
