데이터 처리 안내

내 일정은,
내 손 안에.

보호자가 가져온 학교 안내문과 메시지, 아이들 일정, 내부 AI 모델과 선택적 ChatGPT 연결을 현재 Android 구현에서 처리하는 방식을 설명합니다.

01 · 일정과 체크리스트

일정과 준비물 체크리스트는 Android 앱의 로컬 저장소에서 관리합니다. 사용자가 내용을 확인하고 직접 저장해야 등록됩니다. 기존 외부 캘린더 동기화와 백그라운드 일정 자동 등록은 현재 제공하지 않습니다.

02 · 내부 AI 모델 분석

내부 AI 모델은 약 1GB 파일을 한 번 다운로드한 뒤 기기에서 실행합니다. 최초 다운로드에는 인터넷 연결이 필요하며 이후 분석은 인터넷과 ChatGPT 연결·구독 없이 사용할 수 있습니다. 사용자가 선택한 글과 사진에서 읽은 텍스트를 기기 안에서 처리하고, 분석 원문을 외부 서버로 전송하지 않습니다.

사진은 기기에서 글자를 읽은 뒤 내부 AI 모델로 분석합니다. 원문에 있는 일정과 준비물만 추출하며 추가 준비물 추천은 하지 않습니다. 분석 결과는 사용자가 확인·수정하고 직접 저장해야 등록됩니다. 설정에서 AI를 끄거나 모델 파일을 삭제할 수 있으며 저장한 일정은 유지됩니다.

03 · 선택적 ChatGPT 분석

ChatGPT 방식으로 사용자가 분석을 시작하면 선택한 텍스트 원문 또는 사진이 OpenAI로 전달됩니다. 최초 연결 전에 전송과 ChatGPT 구독 사용량 차감 가능성을 안내합니다. 계정을 연결했다고 저장된 모든 일정이나 수집 원문이 분석에 전달되는 것은 아닙니다.

GPT 사진 분석은 OCR 텍스트로 바꾸지 않고 이미지 자체를 전달합니다. 원문 준비물은 일정 분석에 포함하며, 추가 준비물 추천은 해당 버튼을 누를 때만 별도로 요청하고 AI 추천으로 구분합니다.

04 · 계정 연결과 해제

시스템 브라우저에서 로그인하며, 앱은 ChatGPT 비밀번호나 API 키 입력을 요구하지 않습니다. 연결 정보는 Android Keystore로 암호화해 앱 전용 저장소에 보관합니다. 연결을 해제하면 연결 토큰을 삭제하며 저장한 일정은 유지됩니다.

05 · 카카오톡 알림 원문

사용자가 Android 알림 접근 권한을 허용하고 채팅방 또는 발신자 이름 조건을 설정할 수 있습니다. 조건에 맞는 알림 원문을 앱에서 보관합니다. 수집·필터 단계에서 AI를 실행하거나 OpenAI에 원문을 전달하지 않습니다. 사용자가 원문을 선택해 일정 확인을 열었을 때 분석하며 전체 대화 기록을 읽는 기능은 아닙니다.

06 · AI 없이 직접 입력

ChatGPT 연결이나 내부 AI 모델 다운로드 없이 직접 입력과 기본 자동 채우기로 일정을 관리할 수 있습니다. AI 없이 사용하는 경우 AI 분석·추천을 실행하지 않으며, 사용자가 직접 확인한 뒤 저장한 일정은 앱의 로컬 저장소에서 관리합니다.

07 · 이 소개 웹사이트

정적 제품 소개 사이트로 로그인, AI 분석, 문의 양식이나 일정 데이터베이스가 없습니다. 분석 추적 스크립트와 외부 삽입 콘텐츠를 사용하지 않습니다. 언어 선택은 현재 브라우저의 로컬 저장소에만 저장하며 앱 개발자에게 전송하지 않습니다. GitHub Pages에 호스팅하는 경우 호스팅 요청은 GitHub의 정책에 따라 처리됩니다.

08 · 서비스 상태

앱은 개발 중이며 OpenAI 연동 승인과 실계정·실기기 검증이 필요합니다. 계정 인증 권한만으로 ChatGPT 플랜 기반 AI 분석 권한이 부여되는 것은 아닙니다. 승인된 연동 범위, 계정 자격과 사용량 한도를 따릅니다.

이 페이지는 현재 구현의 기능 설명이며 완전한 운영 개인정보 처리방침은 아닙니다. 공개 서비스 출시 전 운영 주체, 실제 문의처, 보관·삭제 절차 등 전체 정책을 확정해야 합니다.
